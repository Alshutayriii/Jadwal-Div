# جدول المدرسة Pro — نسخة الويب (React + Vite + PWA)

تطبيق عربي RTL لإدارة الجداول الدراسية، يعمل **دون إنترنت** ويحفظ كل شيء محليًا في المتصفح. هذه النسخة مبنية لتكون متوافقة مع [Lovable](https://lovable.dev) وللنشر كـ PWA على أي استضافة ثابتة.

## التشغيل

```bash
npm install
npm run dev       # تطوير — http://localhost:5173
npm run build     # فحص TypeScript + بناء الإنتاج + Service Worker
npm run preview   # معاينة الإنتاج — http://localhost:4173
```

## الحسابات التجريبية

| الدور | المستخدم | كلمة المرور |
|---|---|---|
| مدير النظام | `admin` | `admin123` |
| مدير المدرسة | `principal` | `principal123` |
| وكيل المدرسة | `vice` | `vice123` |
| مسؤول الجدول | `scheduler` | `scheduler123` |
| معلم | `teacher` | `teacher123` |

كلمات المرور تُجزّأ محليًا بـ **PBKDF2-HMAC-SHA256** (150,000 تكرار) عبر WebCrypto عند أول تشغيل. غيّرها من صفحة «المستخدمون» قبل أي استخدام حقيقي.

## البيانات والتخزين

- المفتاح: `stp-react-db-v1` في `localStorage`.
- لا يوجد خادم ولا API ولا Supabase ولا تتبع.
- النسخ الاحتياطي: «الإعدادات ← تنزيل نسخة JSON»، والاستعادة من الملف نفسه.
- «إعادة البيانات التجريبية» ترجّع البذرة الأصلية وتحذف الإضافات.
- البيانات لكل متصفح/جهاز على حدة؛ لا مزامنة.

## PWA

- `vite-plugin-pwa` بوضع `generateSW` وتحديث تلقائي.
- precache للأصول والخط والأيقونات، ويعمل بعد أول تحميل دون إنترنت.
- يتطلب HTTPS (أو `localhost`) لـ Service Worker وWebCrypto.

## الرفع على Lovable

1. ارفع محتوى هذا المجلد إلى مستودع GitHub (بدون `node_modules/` و`dist/`).
2. في Lovable اختر **Import from GitHub**، أو ابدأ مشروعًا فارغًا واسحب الملفات.
3. تأكد من تشغيل `npm run build` محليًا قبل الرفع.

إن أردت بناء النسخة من الصفر عبر البرومبت، فراجع `../LOVABLE.md`.

## ما تم التحقق منه

- بناء TypeScript/Vite ناجح، وحزمة إنتاج + Service Worker.
- 420/420 حصة موزعة بلا تعارض، ونشر ناجح.
- 90 مناوبة إشراف (6 مواقع × 5 أيام × 3 فترات) بلا شاغر.
- غياب وانتظار تلقائي مع بديل.
- 12 تقريرًا، CSV بـ BOM، XLSX صالح، طباعة عربية.
- استيراد CSV للتقويم.
- نسخ/استعادة/إعادة بذر، وثبات `localStorage` بعد إعادة التحميل.
- تشغيل كامل بعد إيقاف الخادم (Service Worker).
- 0 أخطاء console في المسارات المختبرة.

## الحدود

- لا APK/IPA أصلي؛ الجوال عبر PWA.
- PDF عبر نافذة الطباعة لا كتنزيل مباشر.
- لا مزامنة بين الأجهزة.
- الحل الجدولي heuristic؛ المدخلات شديدة التزاحم قد تُبقي حصصًا غير موزعة وتصرّح بها.
