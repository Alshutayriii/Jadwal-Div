# جدول المدرسة Pro — نسخة الويب (React + Vite + PWA)

تطبيق عربي RTL لإدارة الجداول الدراسية، يعمل **دون إنترنت** ويحفظ كل شيء محليًا في المتصفح. هذه النسخة مبنية لتكون متوافقة مع [Lovable](https://lovable.dev) وللنشر كـ PWA على أي استضافة ثابتة.

## التشغيل

```bash
npm install
npm run dev       # تطوير — http://localhost:5173
npm run build     # فحص TypeScript + بناء الإنتاج + Service Worker
npm run preview   # معاينة الإنتاج — http://localhost:4173
```

## الحسابات التجريبية

| الدور | المستخدم | كلمة المرور |
|---|---|---|
| مدير النظام | `admin` | `admin123` |
| مدير المدرسة | `principal` | `principal123` |
| وكيل المدرسة | `vice` | `vice123` |
| مسؤول الجدول | `scheduler` | `scheduler123` |
| معلم | `teacher` | `teacher123` |

كلمات المرور تُجزّأ محليًا بـ **PBKDF2-HMAC-SHA256** (150,000 تكرار) عبر WebCrypto عند أول تشغيل. غيّرها من صفحة «المستخدمون» قبل أي استخدام حقيقي.

## أهم الميزات (1.1.0)

- **تحرير بالسحب والإفلات**: انقل أي حصة أو بدّلها بالسحب، مع معاينة حيّة للخانة (أخضر = صالح، أحمر = تعارض وسببه). النقل الذي يُنشئ تعارضًا صارمًا يُرفض ولا يغيّر الجدول.
- **تراجع/إعادة**: كل تعديل (إضافة/حذف/نقل/تبديل/تثبيت) يُسجَّل في لقطات داخلية حتى 40 خطوة — `Ctrl+Z` و`Ctrl+Shift+Z` / `Ctrl+Y`.
- **PDF حقيقي بجودة طباعة**: زر «PDF الشعبة» في الجدول و«PDF احترافي» في التقارير يُنشئ ملف A4 داخل المتصفح بترويسة المدرسة والشعار والتاريخ ورقم الصفحة، دون نافذة طباعة. العربية تُرسم بتشكيل صحيح لأن الصفحات تُصدَّر كصور عالية الدقة.
- **محرك جدولة أذكى ومؤشر جودة**: عقوبات للفراغات وتجاور الحصص، تحسين محلي محدود بعد البناء، ومؤشر `0–100` معلن الصيغة (تغطية 55% + فراغات 18% + انتشار 12% + عدالة 8% + توازن 7%)، يظهر في لوحة التحكم والجدول وتقرير «جودة الجدول».
- **مشاركة ونسخ احتياطي متقدم**: رمز QR لجدول الشعبة (ضغط `deflate-raw` ثم Base64، نحو 900 بايت بدل 3278)، مشاركة نظام/نسخ نص، نسخة مشفّرة AES-256-GCM بمفتاح PBKDF2 (150 ألف تكرار)، لقطات محلية حتى 8 مع مقارنة A/B قبل الاستعادة.
- **وصول سريع وتجربة جوال**: بحث شامل `Ctrl+K` في الصفحات والمعلمين والشعب والمواد، نافذة اختصارات (`؟`)، شريط تنقل سفلي للجوال، جولة تعريفية 5 خطوات تُعاد من الإعدادات، وروابط عميقة (`#/timetable?section=3`، `#/reports?type=teacher_schedule&teacher=5`).
- **حفظ الجلسة**: تبقى مسجّلًا بعد إعادة تحميل الصفحة (محليًا فقط).

## البيانات والتخزين

- المفتاح: `stp-react-db-v1` في `localStorage`.
- لا يوجد خادم ولا API ولا Supabase ولا تتبع.
- النسخ الاحتياطي: «الإعدادات ← تنزيل نسخة JSON»، والاستعادة من الملف نفسه.
- النسخة المشفّرة: AES-256-GCM + PBKDF2-SHA256 (150,000 تكرار) — لا تُفتح دون كلمة المرور.
- لقطات سريعة في المتصفح (حتى 8) مع تقليم حجمي، ومقارنة أعداد الكيانات وفروق الحصص بين أي لقطتين.
- الجلسة: `stp-react-session-v1`، واللقطات: `stp-snapshots-v1`.
- «إعادة البيانات التجريبية» ترجّع البذرة الأصلية وتحذف الإضافات.
- البيانات لكل متصفح/جهاز على حدة؛ لا مزامنة.

## PWA

- `vite-plugin-pwa` بوضع `generateSW` وتحديث تلقائي.
- precache للأصول والخط والأيقونات، ويعمل بعد أول تحميل دون إنترنت.
- يتطلب HTTPS (أو `localhost`) لـ Service Worker وWebCrypto.

## الرفع على Lovable

1. ارفع محتوى هذا المجلد إلى مستودع GitHub (بدون `node_modules/` و`dist/`).
2. في Lovable اختر **Import from GitHub**، أو ابدأ مشروعًا فارغًا واسحب الملفات.
3. تأكد من تشغيل `npm run build` محليًا قبل الرفع.

إن أردت بناء النسخة من الصفر عبر البرومبت، فراجع `../LOVABLE.md`.

## ما تم التحقق منه

- بناء TypeScript/Vite ناجح، وحزمة إنتاج + Service Worker.
- 420/420 حصة موزعة بلا تعارض لثلاث بذور (42، 7، 2026) في 30–60 مللي ثانية، 0 أخطاء و0 تنبيهات و0 عجز (سكربت `scripts/verify-quality.mjs`).
- جودة 87–88/100 عند التوليد من الصفر دون حصص مثبتة؛ وجود تثبيتات قديمة يخفض المؤشر كما هو متوقع.
- 90 مناوبة إشراف (6 مواقع × 5 أيام × 3 فترات) بلا شاغر.
- غياب وانتظار تلقائي مع بديل.
- 13 تقريرًا، CSV بـ BOM، XLSX صالح، وPDF عربي حقيقي (تنزيل مباشر) — تحقق من ملفات فعلية في المتصفح.
- سحب/تبديل ناجح مع تراجع وإعادة، ورفض حركة متعارضة برسالة واضحة دون تغيير الخلية.
- QR بحزمة مضغوطة (903 بايت) مع فكّ صحيح للبيانات، ولقطة محلية، ونسخة مشفّرة (81 مللي ثانية، رفض كلمة المرور الخطأ).
- Ctrl+K، نافذة الاختصارات، الجولة التعريفية، والروابط العميقة.
- تشغيل كامل بعد إيقاف الخادم (Service Worker: 35 أصلًا في الكاش، وإعادة تحميل ناجحة).
- 0 أخطاء console في المسارات المختبرة.

## الحدود

- لا APK/IPA أصلي؛ الجوال عبر PWA.
- صفحات PDF صور عالية الدقة (لتشكيل عربي سليم)؛ النص غير قابل للتحديد/البحث.
- لا مزامنة بين الأجهزة، والبيانات لكل متصفح على حدة.
- QR يحمل جدول شعبة واحدة؛ الجداول الكبيرة جدًا قد تتجاوز سعة الرمز فيُعرض النص بدلًا منه.
- الحل الجدولي heuristic؛ المدخلات شديدة التزاحم قد تُبقي حصصًا غير موزعة وتصرّح بها.
